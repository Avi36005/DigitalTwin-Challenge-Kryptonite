## People by diabetes group and exclusions

* ShanghaiT2DM: 100 people with Type 2 diabetes in 109 recordings; 2 below the declared 72 observed-hour minimum (70.2 observed hours below the 72 h minimum; 61.8 observed hours below the 72 h minimum). 16 ShanghaiT1DM files in the same archive were not imported (Type 1).

## Matched wearable and profile data

## Duplicate and overlap checks

Shift-invariant recording signatures were compared for 199 recordings (19,656 cross-recording pairs). Largest overlap 0.1706 (flag threshold 0.5); flagged pairs: 0. Exact duplicate samples and readings repeated across a participant's overlapping recordings are marked `duplicate` in the canonical layer. No attempt is made to link people across unrelated datasets.

## Access-blocked and planned sources

* **AI-READI v3** — `access_required`. No local AI-READI files. Completed without access: Open mHealth CGM JSON parser (fictional fixtures); selective-download planner from a real manifest (fixture-tested); canonical conversion with LOW/HIGH codes and timestamp anomaly checks. Steps only the user can complete:
  1. Create or provide an Azure Storage container to receive the data (required by the FAIRhub workflow).
  2. Log in to FAIRhub through CILogon with institutional credentials (or contact the AI-READI Data Access Committee).
  3. Confirm the research is related to Type 2 diabetes.
  4. Answer the training questions on research methods and ethics.
  5. Describe the research purpose (published with your name on the AI-READI website).
  6. Review and accept the AI-READI Dataset License (DLA, "I ACCEPT").
  7. Select only the CGM, participant table, permitted clinical fields and wearable summaries; provide storage details.
  8. Wait for the request to be processed, then download into data/raw/ai_readi/3.0.0 and run `glucotwin data manifest`.
* **Glucose-ML** — `planned`. Discovery resource only. Its harmonized copies overlap CGMacros, ShanghaiT2DM and AI-READI; no component was imported. Catalog totals are never GlucoTwin counts.

## Reproduce

```bash
uv run glucotwin data download                       # CGMacros (opt-in, ~657 MB)
uv run glucotwin data import && uv run glucotwin data canonical
uv run glucotwin data download --dataset shanghai_t2dm   # 3.7 MB, CC BY 4.0
uv run glucotwin data import --dataset shanghai_t2dm
uv run glucotwin data manifest
```
