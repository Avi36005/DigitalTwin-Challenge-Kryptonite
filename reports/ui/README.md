Generated by the Playwright journeys (`make e2e`) on their own API and web server with throwaway session storage,
using the serving model `lightgbm.dyn-prof-v2.gt-primary-2026-10-13-fusion` (profile + dynamic inputs; 1440×900 unless
noted). All recorded-data screenshots were recaptured on 13 Oct 2026 after the serving-model switch.
